# <img src="frontend/public/favicon.svg" width="32" height="32" alt="logo" valign="middle" /> ResearchEase

科研项目全生命周期管理平台 —— 管理科研项目从**申报 → 立项审批 → 进度跟踪 → 经费管理 → 成果验收**的全流程。

> 这是一份全栈开发工程师招聘笔试题的 MVP 实现。原始题目只给了一句话模糊需求，角色划分、功能范围、技术选型均由本人自行设计并在设计文档中记录决策理由。

**在线体验**：[http://106.53.185.34:8082](http://106.53.185.34:8082)　（种子账号见下）

## 功能概览

- **三角色协同**：科研人员（PI）负责申报与执行；管理人员负责立项审批、经费审核、结题验收；系统管理员负责账号管理。
- **项目生命周期状态机**：草稿 → 已提交（可被驳回并重新提交）→ 执行中 → 验收中 → 已结题 / 退回执行中，后端强制校验状态跳转合法性，不只依赖前端按钮显隐。
- **经费预占规则**：预算余额 = 已批准金额 − 已批准支出 − 审批中支出，避免超支。
- **进度汇报**：执行期内可随时提交，不设审批关卡（审核与记录职责分离）。
- **审批记录独立成表**：立项 / 经费 / 验收三类审批各自保留完整历史，多次驳回不覆盖。
- **数据看板**：项目状态分布、经费总览、进度预警（逾期项目）。

## 技术栈

| | |
|---|---|
| 前端 | Vue 3 (Composition API) + Vite + TypeScript + Element Plus + Pinia + Axios |
| 后端 | Java 17 + Spring Boot 3 + MyBatis-Plus + Spring Security + JWT |
| 数据库 | MySQL 8 + Flyway（启动时自动建表 + 灌种子数据） |
| 部署 | GitHub Actions CI/CD，push 到 `main` 自动构建、测试、部署到云服务器 |

## 本地运行

详见 [本地运行指南.md](./本地运行指南.md)，核心步骤：

```bash
docker-compose up -d                      # 启动 MySQL
mvn -f backend spring-boot:run            # 启动后端（自动建表+灌种子数据）
npm --prefix frontend install
npm --prefix frontend run dev             # 启动前端
```
